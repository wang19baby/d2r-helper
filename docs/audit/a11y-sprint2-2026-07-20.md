## 2 · 高风险组件(需修)

### 🔴 CharacterPanel (7 buttons, 0 aria-labels)
- 主要 tab 切换按钮 / 子 tab 切换 / 操作按钮
- spec §1.3.6 8 tab reorder 后,每个 tab 按钮需 `aria-label` 包含 tab 名称
- 建议:`aria-label={\`切换到 \${TABS[idx].label} tab\`}`

### 🔴 TabBar (2 buttons, 0 aria-labels)
- 全局导航组件,关键 a11y
- spec §6 TabBar ArrowLeft/Right/Home/End 键盘已实现,但缺 `aria-label`
- 建议:`aria-label="Tab navigation, use arrow keys"`

### 🔴 D2ConfirmModal (2 buttons, 0 aria-labels)
- 通用确认/取消 modal(spec 6+ 处使用)
- 确认按钮文本通常清晰(如 "确认删除"),但 cancel 按钮 `<X>` 关闭图标缺 aria
- 建议:`aria-label="关闭"` 给关闭按钮
