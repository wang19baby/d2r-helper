主要交互

  • A1 点击 cell → 右侧详情 (4-D) 实时更新 + 上架 (4-E) 预填
  • A2 拖拽 cell 到"上架"按钮 → 自动填入数量
  • A3 双击 cell → 快速预览弹窗 (含 stat_list 详细展开)
  • B1 sub-tab (4-C) 切换不刷新页面,grid 重渲染
  • B2 工具栏 tag-pill 多选过滤,实时刷新 grid
  • C1 "上架"成功后,cell 加金色✓角标,数量减一
  • C2 售出后 4-D 显示"已售出"+ 时间戳,3s 后清除
  • D1 价格步进器 +/− 步长:数量=1,单价=10000
  • D2 "重新报价" → 拉取最近 7 笔成交均价
  • E1 空状态 (扩展仓无物) → 显示 d2emu-drop 风"放入物品"虚线区

断点 & 折叠

  • ≥1280 三栏布局 (280 / 1fr / 320),完整信息
  • 1024-1279 中右两栏合并,详情下移到 grid 下方
  • 768-1023 单栏堆叠,grid 10 列紧凑模式 (compact)
  • <768 列表视图 (隐藏 grid,改 side-list 卡片)
