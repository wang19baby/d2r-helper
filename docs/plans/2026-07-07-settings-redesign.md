# 设置页重构设计文档

## 概览

面向 Mod 制作者/高级玩家的 D2R 市场设置页重构。布局改为 **仪表盘状态卡片 + 折叠面板 (Accordion)**，并引入 **Mod 存档路径联动机制**。

## 顶部状态 Widget（3 列网格）

每个 widget 显示关键状态的摘要，点击可快速跳转到对应折叠面板。

### 游戏 widget
- 图标 + 状态指示（🔴 未配置 / 🟢 已配置）
- 显示游戏根目录（截断）
- 点击 → 展开"游戏目录"面板

### 模组 widget
- 当前活跃 Mod 名称 + 版本
- 资源状态 tag（🟢 已就绪 / 🟡 无数据）
- 点击 → 展开"模组 & 语言"面板

### 存档 widget
- 当前存档路径摘要
- 联动状态标签（🟢 联动中 / ⚡ 独立设置）
- 最近备份时间（"昨天备份" / "尚无备份"）
- 点击 → 展开"存档 & 备份"面板

## 折叠面板设计

所有面板使用 `<details>`/`<summary>` 语义或自定义 Accordion 组件。每个面板 header 有展开/折叠箭头 + 标题 + 右侧操作按钮。

### 1. 游戏目录（默认展开）

```
┌──────────────────────────────────────────────┐
│  ▼ 📁 游戏目录                                │
│                                              │
│  游戏安装目录                                 │

- 只保留「游戏安装目录」一个字段
- 自动检测 `mods/` 目录下的可用模组
- 状态信息（路径有效/无效、模组数量）在 widget 和 hint 中展示

└────────────────────────────────────────────┘
```

**联动设置**（核心新增）：
- 勾选框："切换模组时自动同步存档路径"
- 勾选后，切换 Mod → `save_folder` 自动设为 Mod 的 `savepath`
- 下方显示当前关联的存档路径
- 用户手动修改存档路径 → 联动勾选自动取消

**联动技术规则**：
1. 仅当 Mod 的 `modinfo.json` 包含 `savepath` 字段时，联动复选框才可勾选
2. 勾选联动后切换 Mod → 调用 `update_save_folder` + 刷新存档 widget
3. 如果用户通过"存档"面板手动改了路径 → 联动 checkbox 取消
4. "原版" Mod 无 savepath → 联动自动禁用，tooltip 提示"原版使用默认存档路径"

## 搜索功能

右上角搜索框，实时过滤当前设置项：

```
输入: "存档"
→ 高亮匹配的面板标题和字段标签
→ 自动展开包含匹配内容的面板
→ 折叠不匹配的面板

输入: "联动"
→ 滚动到模组面板，高亮联动复选框
```

- 搜索范围为当前页面所有设置项的 label 和描述
- 搜索时不发起后端请求
- 搜索框支持 ESC 关闭 / 清空

## 关键交互原则

### 保存策略
- **即时保存**（`onChange` 立即调用命令）：语言、版本、仓库格子
- **确认保存**：游戏目录、存档路径（有浏览对话框）
- **联动保存**：切换 Mod + 联动开 → 自动更新存档路径

### 通知反馈
- 成功/失败均使用现有的 Toast 组件
- 联动状态变化有明确的 Toast 提示（"已自动同步存档路径至: ..."）

### 状态一致性
- 顶部 Widget 与面板内状态双向同步
- 修改面板内值 → Widget 自动更新
- App.tsx 的全局 import polling 继续存在，Config 页面无需另起轮询

## 后端改动清单

### 1. `ModMeta` 加 `save_path` 字段
```rust
pub struct ModMeta {
    pub name: String,
    pub version: String,
    pub description: String,
    pub author: String,
    pub save_path: String,  // 新增
}
```

### 2. `read_mod_info()` 解析 savepath
从 `modinfo.json` 读取 `savepath`（兼容 `save_path` / `savedir` 命名）。

### 3. 前端 TypeScript 类型同步
```ts
export interface ModMeta {
  name: string
  version: string
  description: string
  author: string
  save_path: string  // 新增
}
```

### 4. 联动逻辑（纯前端）
- `Config.tsx` 中维护 `linkEnabled` state
- `changeMod()` 中判断：if `linkEnabled && mod.meta.save_path` → 调用 `update_save_folder`
- 存档路径手动变更时 → `setLinkEnabled(false)`
